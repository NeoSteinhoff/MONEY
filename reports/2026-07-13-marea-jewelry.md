### 5-point supplier vetting checklist
1. Confirm PVD (physical vapor deposition) plating process specifically — not electroplating — request the plating spec sheet (micron thickness, base metal grade confirmation as 316L surgical steel).
2. Request salt-spray test certification (ASTM B117) or equivalent tarnish-resistance documentation.
3. Verify nickel-free / hypoallergenic certification — directly addresses the #2 Reddit complaint category (allergic reaction risk) from Section 2.
4. Request 3 existing client references and check for Alibaba Gold Supplier status + Trade Assurance coverage.
5. Order a paid sample batch (5–10 pieces) before any bulk commitment; wear-test one piece in a chlorinated pool and one in seawater for 14 days minimum before confirming the production order.

### Sample order protocol
Week 1: Shortlist 5 suppliers meeting the checklist above → order paid samples (5 units each, ~$50–80 total) → Week 2–3: concurrent 14-day wear test (pool/gym/shower) on all samples while supplier also produces a formal quote for a 100–150-unit MOQ first production run → Week 3: select winner based on (a) surviving the wear test with zero visible degradation, (b) quote and lead time, (c) communication responsiveness → place production order.

### 8-point QC checklist (per batch, before listing live)
1. Visual inspection for plating consistency, no bare-metal patches
2. Clasp function test (100 open/close cycles per sample unit)
3. Chain link tensile pull test (manual, 5kg resistance minimum)
4. Salt-spray/pool-chlorine soak retest on 3 random units per batch of 100
5. Weight consistency check (±0.3g tolerance) — flags base-metal substitution fraud

7. Packaging integrity (branded box closes correctly, care card included, no shipping damage)
8. Length/sizing accuracy against spec sheet (directly addresses Awe Inspired's documented complaint in Section 3)
